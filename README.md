# CatalogCraft – Free All-in-One Shop Website Builder & UI Component Library

A 100% free, open-source, no-code website builder and interactive design platform for shops and small businesses. Build custom, responsive storefronts with **20 coordinated design systems**, **22 pre-loaded business categories**, an **extensive button studio**, and an **interactive UI component explorer**—then export standalone HTML, complete ZIP archives, or share via QR code.

## 🚀 Free Deployment Guide

### Option 1: GitHub Pages (Recommended)
1. Fork or clone this repository:
   ```bash
   git clone https://github.com/Viratkho/web-page-creation.git
   ```
2. In GitHub, go to your repository's **Settings > Pages**.
3. Under **Build and deployment > Source**, choose **Deploy from a branch** and select `main` / `/ (root)`.
4. Your website is live in ~60 seconds with free HTTPS!

### Option 2: Netlify Drop
1. Export the ZIP archive from the builder and extract it.
2. Go to [app.netlify.com/drop](https://app.netlify.com/drop) and drag your folder.
3. Your site is deployed instantly on a custom or free `.netlify.app` domain.

### Option 3: Vercel
1. Import your GitHub repository into Vercel or run:
   ```bash
   npx vercel
   ```

## 🔒 Accessibility & Performance
- **Zero Paid Dependencies**: Runs completely in the browser without mandatory accounts, external servers, or paid AI APIs.
- **WCAG Accessibility**: Includes AAA high-contrast design system, semantic HTML, visible keyboard focus rings, and `@media (prefers-reduced-motion: reduce)` animation suppression.
- **Local Privacy**: All edits and image optimizations happen client-side in the browser.
