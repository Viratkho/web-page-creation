# CatalogCraft – Free Catalogue Builder

A lightweight, serverless catalogue maker and web application with QR code sharing.

## Features
- **Instant Product Catalogue**: Create and customize product catalogues with rich styling, layouts, and categories.
- **Client-Side Compression & QR Sharing**: Entire catalogue state is serialized and compressed into the URL hash, allowing instant sharing without a backend.
- **Live Preview**: Responsive preview modes for Desktop, Tablet, and Mobile devices.
- **Import/Export**: Export catalogues as JSON and import existing templates.

## Usage
Open `index.html` in any modern web browser or deploy directly to GitHub Pages.
